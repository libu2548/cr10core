# Enclosure

In this section, you will find all the **3D-printable parts required to build the printer enclosure**.

The enclosure is made from **2 mm thick transparent extruded PETG sheets**, using panels sized **540 × 680 mm** for the side and 540x540 for the top.

## Included Parts

The enclosure parts include:

- Printer feet
- Top case corners
- Generic corner brackets
- Hinges
- Various mounting parts

The hinges are designed to be assembled using a **dowel pin**.

## Assembly

Most of the enclosure components can be mounted using standard **T-nuts**, making the assembly simple and easy to modify.

The design is intended to be modular, so individual panels or components can be replaced or modified without having to redesign the entire enclosure.
